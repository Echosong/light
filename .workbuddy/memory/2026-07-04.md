## light-codegen Skill vs Light.Generator 对比分析

### 背景
用户要求检测 `light-codegen` skill 能否完全替代 `Light.Generator` 模块，以及该 skill 能否应用到其他大模型。

### 对比结论

**原 Light.Generator 模块（7个服务）:**
1. DtoService → DTO/QueryDTO/ListDTO
2. MapperService → Mapper.java + Mapper.xml
3. ControllerService → Controller
4. ImplService → Service 接口 + 实现
5. ViewService → list.vue / add.vue / info.vue
6. DictionaryService → data.html 数据字典
7. JpaCommentService → 同步数据库表/字段备注（ALTER TABLE）

**light-codegen Skill 覆盖情况:**
- 完全覆盖：DTO(3个)、Mapper(2个)、Controller、Service(2个) — 后端 CRUD 全套
- 部分覆盖：数据字典 data.html（有模板但无全量合并逻辑）
- 未覆盖：
  1. **Vue 视图生成**（list.vue/add.vue/info.vue）— SKILL.md 中标注为"预留"
  2. **数据库备注同步**（JpaCommentService）— 需要 JDBC 连接执行 ALTER TABLE 语句

**结论：不能完全替代。** 后端代码生成可完全替代，但 Vue 前端视图和数据库备注同步缺失。

### 跨大模型兼容性

Skill 内容（SKILL.md 指令 + references 规则 + templates 模板）是 LLM 无关的纯文本：
- **WorkBuddy**：原生支持，自动加载 + 文件读写
- **Cursor/Windsurf/Cline**：SKILL.md 可作为 .cursorrules，有文件读写能力
- **GitHub Copilot**：内容可放入 .github/copilot-instructions.md，IDE 内有文件能力
- **ChatGPT/Claude/Gemini（网页版）**：作为 system prompt 使用，无文件读写需手动保存生成代码

关键差异在"文件读写能力"而非"理解能力"。

## light-codegen Skill 补充 Vue 视图生成

### 背景
用户要求完善 skill 中的 Vue 视图生成功能，补齐之前缺失的 list.vue/add.vue/info.vue。

### 新增文件
- `references/templates/listVue.tpl` — list.vue 模板（查询表单 + 表格 + 分页）
- `references/templates/addVue.tpl` — add.vue 模板（Drawer 表单 + 验证规则）
- `references/templates/infoVue.tpl` — info.vue 模板（Descriptions 详情展示）
- `references/templates/listVue.md` — list.vue 生成规则文档
- `references/templates/addVue.md` — add.vue 生成规则文档
- `references/templates/infoVue.md` — info.vue 生成规则文档

### 修改文件
- `SKILL.md` — 新增 3.5 节 Vue 视图生成；CodeTypeEnum 加入 LIST_VIEW/ADD_VIEW/INFO_VIEW；注意事项补充 Vue 相关条目
- `references/annotations.md` — @AutoEntity 去掉"预留"标记；@AutoEntityField 补充 HtmlTypeEnum 完整枚举表；CodeTypeEnum 补充 Vue 类型
- `references/path-rules.md` — 新增 Vue 视图输出路径规则；示例文件列表补充 Vue 文件

### 关键生成规则
1. **list.vue**：查询表单按 @InQueryDTO 字段类型生成（String→input, Date→range-picker, 枚举→input-enum, SELECT→select-data）；表格列按非 @NotinListDTO 字段生成 JSON 数组
2. **add.vue**：按 htmlType 生成表单组件（INPUT/SELECT/RADIO/TEXTAREA/UPLOAD/FILE/TEXTEDIT）；验证规则从 Jakarta Validation 注解提取；TEXTEDIT 需额外 ref 声明和内容提取
3. **info.vue**：按字段生成 descriptions-item，UPLOAD 用 img 标签
4. **Vue 路径**：VUE_PATH + "/system"（Sys前缀）或 "/business"（其他）+ "/" + className
5. **列数阈值**：表格列数 >= 10 时操作列 fixed="right"

### 仍未覆盖
- 数据库备注同步（JpaCommentService）— 需要 JDBC 连接执行 ALTER TABLE
